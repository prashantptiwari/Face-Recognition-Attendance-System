FaceTrack – Face Recognition Attendance Management System

FaceTrack is a Python-based Face Recognition Attendance Management System that automates student attendance using real-time facial recognition. It uses OpenCV and the LBPH (Local Binary Patterns Histograms) algorithm to identify registered students and record their attendance automatically.

The application features a modern Tkinter dashboard, SQLite database integration, attendance statistics, and Excel report generation.

🚀 Features

- Face Recognition: Automatically identifies registered students using the laptop's built-in camera.
- Student Registration: Register students with their name, roll number, and 30 facial image samples.
- Face Model Training: Train the LBPH face recognition model using captured facial images.
- Automatic Attendance: Records the student's roll number, name, date, and time after successful recognition.
- Duplicate Student Prevention: Prevents registration with an already registered roll number.
- Student Management: View and delete registered student records.
- Attendance Records: View the latest attendance entry for each student per day.
- Dashboard Statistics: Displays:
  - Total Students
  - Present Today
  - Absent Today
  - Attendance Rate
- Excel Export: Generate daily attendance reports in ".xlsx" format.
- Student Data Management: Deletes associated attendance records, facial images, and matching rows from previously exported Excel reports when a student is deleted.
- Modern GUI: User-friendly dashboard developed using Tkinter.
- Camera Sound Notification: Plays a notification sound after successful attendance recording.

📦 Installation and Setup

1. Clone the Repository

Open your VS Code terminal and run:

git clone https://github.com/your-username/FaceTrack.git

Navigate to the project directory:

cd FaceTrack

2. Install Required Libraries

Install the required Python packages:

pip install opencv-contrib-python numpy pandas pillow openpyxl

Important: Use "opencv-contrib-python" instead of "opencv-python" because the project requires the OpenCV Face module for LBPH recognition.

3. Run the Application

Execute the Python file:

python main.py

The FaceTrack dashboard will open.

📖 How to Use

Follow these steps to manage student attendance:

Step 1: Register Student

- Click on "Register Student".
- Enter the student's name.
- Enter the student's roll number.
- Allow the application to capture 30 facial samples using the laptop camera.

Step 2: Train Face Model

- Click on "Train Face Model".
- The system will process the captured facial images.
- The trained model will be saved as "face_model.yml".

Step 3: Start Camera

- Click on "Start Camera".
- Look directly at the laptop camera.
- The system will detect and recognize the registered face.
- After successful recognition, attendance will automatically be recorded.

Step 4: View Attendance

- Click on "Attendance Records" to view recorded attendance.
- Click on "View Students" to see registered students.

Step 5: Export Attendance Report

- Click on "Export to Excel".
- The system generates an Excel report containing student details, attendance date, latest attendance time, and present/absent status.

Step 6: Delete Student

- Click on "Delete Student".
- Enter the student's roll number.
- Confirm deletion to remove the student's registration, attendance history, facial images, and matching records in existing Excel reports.

🧠 Face Recognition Methodology

FaceTrack uses the LBPH (Local Binary Patterns Histograms) algorithm for facial recognition.

The recognition process follows these steps:

1. Capture facial images through the laptop camera.
2. Convert captured images into grayscale.
3. Detect faces using the Haar Cascade Classifier.
4. Resize facial images to 200 × 200 pixels.
5. Train the LBPH face recognition model.
6. Compare detected faces with trained facial data.
7. Identify the student when the recognition distance is below the configured threshold.
8. Record attendance in the SQLite database.

Recognition Threshold: 80

Required Face Samples: 30 per student.
